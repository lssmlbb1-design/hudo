# Урок 2. Telegram-бот учёта тренировок и спортивных результатов

## Что мы построим

Создадим Telegram-бота, который умеет:

- добавлять тренировку;
- сохранять упражнение, подходы, повторения и вес;
- показывать историю;
- считать общий объём;
- сравнивать результат с прошлой тренировкой;
- хранить личную цель;
- показывать статистику за неделю.

## 2. Таблица базы данных

Один простой вариант — хранить всё в JSON-файле:

```python
import json
import os

DATA_FILE = "workouts.json"

def load_workouts():
    if not os.path.exists(DATA_FILE):
        return {"workouts": [], "next_id": 1}
    with open(DATA_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def save_workouts(data):
    with open(DATA_FILE, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
```

Структура в файле:

```json
{
  "next_id": 1,
  "workouts": [
    {
      "id": 1,
      "user_id": 123456,
      "exercise": "Приседания",
      "sets": 3,
      "repetitions": 10,
      "weight_kg": 40.0,
      "distance_km": null,
      "duration_minutes": null,
      "note": "Последний подход был тяжёлым",
      "created_at": "2026-07-28"
    }
  ]
}
```

## 4. Проверка чисел

```python
def parse_positive_int(value):
    try:
        number = int(value)
    except ValueError:
        return None

    if number <= 0:
        return None

    return number


def parse_positive_float(value):
    try:
        number = float(value.replace(",", "."))
    except ValueError:
        return None

    if number <= 0:
        return None

    return number
```

Пользователь может написать `3`, `3.5` или `3,5`. Хороший бот не устраивает драму из-за запятой.

## 5. Расчёты статистики

Для силовой тренировки можно считать объём:

```python
def calculate_volume(sets, repetitions, weight_kg):
    return sets * repetitions * weight_kg
```

Например, 3 подхода по 10 повторений с весом 40 кг дают 1200 кг общего объёма.

Для бега можно сохранить темп:

```python
def calculate_pace(distance_km, duration_minutes):
    return duration_minutes / distance_km
```

## 6. История и личный рекорд

Получить последние записи:

```python
def get_recent_workouts(workouts, limit=5):
    sorted_workouts = sorted(
        workouts,
        key=lambda workout: workout["created_at"],
        reverse=True,
    )
    return sorted_workouts[:limit]
```

Проверить личный рекорд по весу:

```python
def get_max_weight(workouts, exercise):
    weights = [
        workout["weight_kg"]
        for workout in workouts
        if workout["exercise"] == exercise
        and workout["weight_kg"] is not None
    ]

    return max(weights, default=0)
```

## 7. Меню бота

```text
[Добавить тренировку]
[Моя история]
[Статистика недели]
[Мои цели]
[Помощь]
```

Пример ответа:


```text

```

## 8. Связь с ботом очереди

Оба проекта используют одни и те же инженерные идеи:

| Бот очереди | Бот тренировок |
|---|---|
| клиент | спортсмен |
| запись в очередь | запись тренировки |
| статус ожидания | история результата |
| номер позиции | личный рекорд |
| отмена записи | исправление записи |
| администратор | личный профиль |

В обоих ботах есть диалог, состояния, база данных, проверки и отдельный слой бизнес-логики.
